➡️ **Curso en línea:**

## Introducción

Este documento es un **recurso educativo** destinado a estudiantes y no pretende ser un curso exhaustivo. Algunos temas requieren la orientación de un profesor, y se han omitido deliberadamente varios aspectos del desarrollo web. 

Este recurso forma parte de una serie de documentos dedicados al **desarrollo web**, un tema que el autor ha explorado anteriormente a través de dos tecnologías:

* **Java**
* **PHP**

Estos documentos comparten una **estructura educativa similar**, lo que permite comparar las diferentes tecnologías mediante ejemplos análogos.

## Enfoque educativo

A diferencia de muchos libros sobre ASP.NET, este recurso no se centra inmediatamente en la idea de que una aplicación web ASP.NET se puede desarrollar como una **aplicación de Windows**.

En la literatura tradicional sobre ASP.NET:

* la interfaz de usuario se suele crear en entornos de desarrollo integrado (IDE) como **Visual Studio .NET** o **WebMatrix**;
* los **controles gráficos** se colocan dentro de una interfaz visual;
* estos controles tienen **propiedades, métodos y eventos**;

En este documento, estos conceptos se presentan deliberadamente **más adelante en el curso**, ya que se consideran importantes pero **no fundamentales** para comprender el desarrollo web.

## Objetivo principal

La primera parte del documento se centra en los **fundamentos del desarrollo web**, independientemente de la tecnología utilizada (Java, PHP o ASP.NET).

Se presta especial atención a la arquitectura:

**MVC — Modelo / Vista / Controlador**

Esta arquitectura se recomienda con frecuencia para diseñar aplicaciones web estructuradas y fáciles de mantener.

Sin embargo, el enfoque MVC es relativamente incompatible con la filosofía de ASP.NET de diseñar una aplicación web como una aplicación de Windows. Por este motivo, los mecanismos específicos de ASP.NET destinados a aumentar la productividad se tratan **en la segunda parte del curso**.

## Herramientas utilizadas

Este documento se centra exclusivamente en **herramientas disponibles gratuitamente en Internet**, de modo que los alumnos puedan:

* descargarlas fácilmente;
* instalar el entorno en sus ordenadores personales;
* reproducir y experimentar con los ejemplos presentados;

Un apéndice titulado **«Herramientas web»** explica cómo obtener e instalar estas herramientas.
